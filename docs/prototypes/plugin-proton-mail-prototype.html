Proton Mail through Proton Mail Bridge · prototype for slice 10 (#2495) · nothing here connects to anything

Already decided in ADR-0205: Proton Mail is read and sent through Proton Mail Bridge on the same computer, at 127.0.0.1 and nowhere else, with the Bridge address and the Bridge password. It reads and sends exactly as Gmail does: each thread asks once before it reads, and every email asks. It needs a paid Proton plan that includes Bridge. What is left is yours: four questions, each with its answers side by side.

What Bridge's own code says (read November 14, 2026): it listens on 127.0.0.1, IMAP port 1143 and SMTP port 1025 by default, which the user can change in Bridge and which Bridge moves when a port is taken when it is first set up. Its certificate is its own, made for 127.0.0.1, not signed by anyone a computer already trusts. And each computer's Bridge makes its own Bridge password: the same Proton account has a different one on each computer.

1 · Adding an account: Bridge's ports

Bridge shows its ports beside the Bridge password, under the account's Mailbox details. The form always has a name, the Proton address and the Bridge password; the question is how the ports are given.

2 · Trusting Bridge's certificate

A mail program checks that it is talking to the server it means. Bridge's certificate is its own, so no computer trusts it already. Thunderbird asks the user to accept it once. Sotto only ever talks to 127.0.0.1, but another program on the same computer could listen on Bridge's port while Bridge is closed and be handed the Bridge password.

A · Remember it when the account is added recommended

  • Adding the account keeps the certificate Bridge showed. Afterwards Sotto talks only to a Bridge with that certificate.
  • If it changes, as when Bridge is reinstalled, nothing is read or sent, and the account says so:
Private reader@proton.me. Bridge password saved November 14.

Bridge’s certificate has changed since this account was added, so Sotto is not using it. If you reinstalled Bridge or reset it, trust the new one.

B · Trust whatever answers on 127.0.0.1

  • No certificate is remembered and nothing asks. A reinstalled Bridge just works.
  • A program on this computer that listens on Bridge's port while Bridge is closed would be sent the Bridge password.

3 · When Bridge isn't running

A read or a send that finds nothing on Bridge's port tells the thread "Proton Mail Bridge isn't running on this computer" either way. The question is whether the page says so too.

A · The row says so, looked at when the page opens recommended

Proton Mail Bridge isn’t running
Private reader@proton.me. Bridge password saved November 14.

Proton Mail Bridge isn’t running on this computer, so threads can’t read or send this account’s mail. Open Bridge, then look again.

Sotto knocks on Bridge's port when the page opens and when Look again is pressed, and sends nothing. Running, the row reads "Private" with the usual dot.

B · Only the thread is told

Proton Mail Private

The page never knocks on Bridge. A thread whose read or send finds Bridge closed is told, and its agent tells you.

4 · Paired computers

A Gmail account is copied to a paired computer so its threads can use it. A Proton account cannot simply be copied: each computer's Bridge has its own Bridge password, so the one from this computer would be refused there.
