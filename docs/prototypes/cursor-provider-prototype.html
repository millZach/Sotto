Cursor as a thread provider

The open question: how should signing in to Cursor look on its tile? Switch between A, B and C with the bar at the bottom, or with the Left and Right arrow keys.

Everything else here is decided and is the same in all three. Cursor is an Owl feature at first, so all of it shows only in Sotto Owl. The cube is a placeholder for Cursor's mark.

1. Settings › Providers

The Cursor tile beside Grok Build's. Pick a state to see it, or press through the sign-in from Not signed in. Sign-in is the part that changes between A, B and C.

2. New thread

Cursor is a tile on the model menu's provider rail. Its models open on their makers; choose one to see its models, or type to search them all. Escape steps back one level. Each chip opens its menu above itself, as in the app.

3. A Cursor thread

A reply's More menu, then the three kinds of request card Cursor sends: a permission, its own question tool (cursor/ask_question) and its plan tool (cursor/create_plan). Answer each to see what replaces it.
