2 · What the cluster is doing

Each state differs by shape and motion as well as colour, and the motion comes from the server, not from a timer.

IdleDim and still.
Reading the promptOne cell walks round, slowly. It means working, with no progress implied, since the server reports none.
WritingA: each piece of text that arrives moves a lit cell one step, with a fading trail. Faster text, faster turn; a stall stops it dead.
Not answeringHollow cells, one blink per try. Hollow rather than grey, so it reads apart from idle without colour.
DoneAll four light once, then settle to idle.
