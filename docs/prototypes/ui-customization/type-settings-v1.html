Add a text size to Appearance.

Read tokens.css and 3 more

Every size in the window is a --tt-type-* step, so one multiplier on the root moves all of them together.

/* tokens.css */
--tt-type-body: calc(14px * var(--scale));
--tt-type-lead: calc(16px * var(--scale));

The terminal keeps its own size.
