Make Sotto yours: change anything in the window

T3 Code lets you write CSS for any part of its window, and lets an agent do it for you. Claude Code goes further with mods: code that restyles it and adds parts of its own (a pane, a band above the prompt, a status line, a menu row). These three variants show how Sotto could do the same. The window on the right is a mock. Every change paints it live, and nothing is saved. “Ask a thread” is simulated: it knows oak sidebar, roomy composer, no times, checks above the composer, today’s spend and clock in the strip.
