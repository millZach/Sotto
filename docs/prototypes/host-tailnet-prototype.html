Prototype · Sotto · hosts over the tailnet

Reach forge over your tailnet, and start it at boot

Today every connection to forge is an SSH sign-in, and with Tailscale SSH in check mode each relaunch of Sotto asks for an approval. After forge restarts, its threads are gone until this computer connects and starts the host again. Here a paired desktop reaches forge over its tailnet first, through the Tailscale Serve setting Sotto already owns there, and uses SSH only when the tailnet does not answer or for a press that needs it. On Linux, forge's host can start at boot.

Three layouts. A puts it on the row and its More menu. B gives forge a dialog of its own. C leads with setup: Add host proves the tailnet and offers the boot start, and a host saved before this gets a one-time line. The bar at the bottom switches layout (← →), state (keys 1–9 and 0, or press a state), theme, motion and window size.

Picked (October 5, 2026, the owner's delegated pick): C with A's controls. Recorded in ADR-0053 and ADR-0054.
