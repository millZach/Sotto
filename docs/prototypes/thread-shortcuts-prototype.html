Keyboard shortcuts for threads prototype — throwaway

B chosen: shortcuts get their own Settings › Keyboard page — shown first below. Today Sotto’s thread chords are fixed in code — New thread ⌘⇧N, Changes ⌘D, Terminal drawer ⌘J — and Settle has no keys at all. This mock-up makes them editable with the same press-to-record control Dictation shortcuts already use, keeps every shipped chord as its default, and adds the missing ones. Click any shortcut chip and press keys to try recording (Esc cancels, ⌫ clears). When you are not recording, pressing a bound chord fires it in the strip below. A and C remain on the bottom switcher for reference.

Try it: press ⌘⇧N or ⌘⇧E anywhere on this page.

What gets a shortcut


New: Settle thread, Restore settled thread, Close pane, Next / Previous thread, Next thread waiting on you, Focus the prompt, Stop the running turn. Made editable, same defaults: New thread, Open beside, Zoom pane, Changes, Terminal drawer, the branch bar trio (Branch, Working copy, Previous working copy), Add selection to prompt. Shown but fixed: sending a prompt, Settings, room switching, terminal text keys, and dictation itself — dictation keeps its own rows in Settings › Dictation and always wins a tie, exactly as the code behaves today.



How it operates


    
  
  • Record by pressing, never by typing. Click a chip, press the keys, release — saved at once, no Apply. Esc cancels; ⌫ while recording clears to “No shortcut”. A dot marks a changed row, with a one-row reset (↺).
    • 
  
  • Sane chord rules. A thread shortcut needs ⌘/Ctrl (so plain typing can never trigger one) plus a letter, number, arrow, or . / , / Enter. Modifier-only and Fn chords are refused here — those belong to dictation’s key listener.
    • 
  
  • Conflicts refuse, never steal. If the keys already do something — another row, dictation, or a fixed chord — the row says whose they are and keeps the old keys, mirroring the dictation rows’ wording.
    • 
  
  • One source of truth. Bindings live in one settings field (threadShortcuts, T3 chord spelling like mod+shift+n); menus, tooltips, and aria-keyshortcuts all read from it, so a button can never advertise stale keys. Damaged entries repair to defaults, like the dictation hotkey does today.
    • 
  
  • Window-scoped and polite. These chords work only while Sotto is focused (dictation stays the one global exception), and they stand down in terminals, dialogs, and text fields where the keys already mean something.
    • 
  
  • Settle asks what Settle asks. ⌘⇧E runs the same flow as the Settle button — including the worktree question when one applies; the chord starts it, it never answers it.
