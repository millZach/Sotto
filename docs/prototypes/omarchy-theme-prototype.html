    What each mapping takes
    
    
    M1 · Faithful
    Every role from the colors.toml key of the same name, as T3 Code’s template does: the room is background, the sidebar dark_background, cards lighter_background, muted text dark_foreground, the chosen thread selection, errors red.
    Sotto looks exactly like the terminal beside it. It also takes each theme’s quirks:  And it takes status colours by name, so 
    
    
    M2 · Quiet
    Sotto keeps its own room, sidebar and text, light and dark, and takes the accent. The chosen thread, hover and accent text are mixed from it. Red and yellow come along only where their hue means error and warning and they read on Sotto’s room with a mix of 35% or less; otherwise Sotto’s own.
    Always Sotto, always readable, and the only mapping that can paint both halves of every theme. But beside an Omarchy window it reads as another app: the room is near-black or paper whatever the theme, and only the accent says which theme you chose.
    
    
    M3 · Shaped
    The theme’s background, foreground and accent, laid out as Sotto lays out its own palettes: the sidebar a step from the room toward the text (lighter in dark, darker in light, as Ink and paper are), cards and the message bubble a few percent further, the chosen thread tinted with the accent, muted text a fixed blend of text into room. Status colours as in M2.
    The room matches the terminal beside it and the window still has Sotto’s shape. It reads five keys every theme sets with care, rather than fifteen that mean different things in different themes (White’s lighter_background is a mid grey; light_foreground is brighter than the text in Tokyo Night and dimmer in Catppuccin Latte).
    

    
    Light and dark
    
    
    Omarchy themes come one mode at a time, and every switch also sets GNOME’s color scheme, which Sotto’s Match Linux follows. Under M1 and M3, Omarchy paints only the column of the mode its theme has. Chosen in both columns, it waits in the other one, and Sotto’s own palette stands in only if you force that mode with Light or Dark. Under Match Linux that never shows: Linux turns dark exactly when Omarchy does. Catppuccin is the one stock pair (Catppuccin and Catppuccin Latte). M2 builds both halves from Sotto’s own, so it can be chosen in both columns.
    

    
    How the guard repairs
    
    
    Omarchy’s templates substitute keys and blend two keys by a fixed amount. They cannot measure, so no template can promise 4.5:1 for every theme. The template does what a fixed blend can, as T3 Code’s mix red foreground 35% does. Then Sotto checks the rendered file when it loads it: each text colour is measured on every surface it sits on, and one that falls short is mixed toward the text by the smallest whole percent that reads 4.5:1 (3:1 for the focus ring and the live dot). When the ink on the accent button fails, the button moves toward the text instead. Nothing is written back: the file stays what Omarchy rendered.
    
    
    Across the 22 stock themes, each in its own mode, the templates alone fail  of  checks. After the guard none fail.
    

    
    Status colours
    
    
    Omarchy’s red and yellow are terminal colour slots, and some themes fill them with other hues: . M1 takes them by name. M2 and M3 take a theme’s red only where its hue reads as red (OKLCH hue 345° to 45°, chroma 0.07 or more) and its yellow only where it reads as amber or yellow (45° to 105°), and only where a mix of 35% or less toward the text makes it read on the room. Otherwise they use Sotto’s own red and amber, so a warning stays amber rather than mixing down to brown (Rose Pine’s yellow would need about two thirds).
    
    
    Green has no theme role. Sotto’s finished ring is its own green in every mapping, checked here at 3:1 on the room and the sidebar. Adding a success role would break the T3 theme file format that ADR-0011 keeps compatible, so no template writes green.
    

    
    The pill
    
    
    The pill is an omarchy-shell plugin and paints from Omarchy’s palette, as the bar does, so no mapping changes it: its text reads  on its background in this theme. What changes is how Sotto’s window sits beside it.
    

    
    How it reaches Sotto
    
    
      
      
    • Sotto installs the template as ~/.config/omarchy/themed/sotto.json.tpl and leaves it alone after that, so a user’s edit stays. Omarchy renders it to ~/.local/state/omarchy/current/theme/sotto.json on every switch.
      • 
      
    • Omarchy removes the whole theme folder and moves the new one in, so Sotto watches current for the folder, not the file.
      • 
      
    • A rendered file that still holds {{ is refused and the last palette stays, as omarchy-theme-set-t3code does.
      • 
      
    • The file is a T3 theme file (version 1) with the id omarchy, so it passes the same canonical-colour checks as an imported theme.
      • 
      
    • Checked on forge: all three templates rendered by omarchy-theme-set-templates itself, under a throwaway home, for the 22 stock themes. Every placeholder resolved, and every value matches what this page computes.
      • 
    
    

    
    How this sits with ADR-0011 and ADR-0024
    
    
    The Omarchy theme is one more theme in the library, in the file format and role set ADR-0011 keeps, so the token test applies to it unchanged. It is not a built-in and not one of Your themes: it is listed only on Omarchy, cannot be edited or removed, and changes when Omarchy does. ADR-0024’s two columns stay; Omarchy is an option in each column whose half it carries. Colour still comes from the chosen theme, never the component. The guard only moves a colour the theme chose until it reads. Whichever mapping is picked, a new ADR records it, the guard and the hue rule, and amends ADR-0024’s gallery.
    

    
    Designer’s recommendation
    
    
    
      
    M3, shaped. Tiled beside a terminal, its room is the terminal’s colour, and the window still has Sotto’s shape: the sidebar a step toward the text, an accent-tinted chosen thread, red and amber that mean what they say. Its template reads the five keys every theme sets with care, and the guard has  checks to repair across the 22 stock themes, against  for M1.
    
      
    M1 is the closer copy, but it fails where Sotto’s text is quietest (muted text and timestamps) in most themes, and it turns errors green on Hackerman. M2 is the safest, but beside any Omarchy window it reads as a different app; it is the better fallback if the owner wants Sotto to keep its own look on Omarchy.
