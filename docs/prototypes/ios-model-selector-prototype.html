Model selector in the iPhone reply box

Press the pill. Current model at the top, then favorites, then each provider closed. Press a provider to open it; opening another closes it. Older models sit under Legacy inside a provider. On a phone, these switches are below the mock.

Device

What each variant is

  • A, Fold-out menu. Looks like the iOS menu the pill opens today. A provider folds open in place under its row; the rest stay where they are. Sotto draws it itself, because the iOS menu can't fold rows open.
  • B, iOS submenus. The real iOS menu. A provider opens its own submenu over the first, with its name at the top to go back. One open at a time comes for free. Legacy is a third level.
  • C, Sheet. The pill opens a half-height sheet with the same list in rounded groups. More room and bigger rows, but the composer is covered.

The same in all three

  • Opens scrolled to the top, every provider closed, the current model's included.
  • Favorites leave out the current model, which already heads the list.
  • A thread can only change to its own provider's models, so its list has one provider and favorites from that provider only. Watcher's lists every provider it runs on.
  • Effort, Speed and Permissions stay in the same menu, after the providers.
