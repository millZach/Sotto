# Parallel coding-agent workbenches and the command-center pattern

Researched 2026-10-08. Scope: thirteen independent workbench families and the 2026 newcomer cmux, using vendor docs, dated releases, source code and direct issue reports. No software was installed or run; observed means source, release or issue evidence, documented means a vendor claim, and inferred means a design reading for Sotto.

## Summary

- **The lane now includes real managers.** Observed: Agent Deck has a persistent Conductor and profile-scoped Maestro; Superset ships an orchestration skill. Lists and boards are no longer the whole comparison. [Agent Deck Command Center](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/docs/COMMAND-CENTER.md), [Superset orchestration](https://github.com/superset-sh/superset/blob/edcec5b936643560165b90af730d70d742616156/apps/docs/content/docs/orchestration.mdx).
- **The most instructive control API is explicit about identity and delivery.** Inferred: T3 V2's app-owned threads, incremental reads and retry-safe sends fit Sotto closely, but this is preview/nightly behavior, not verified stable rollout. Nimbalyst's Meta Agent is also real, but alpha and workspace-scoped. [T3 tools](https://github.com/pingdotgg/t3code/blob/393ff4c968073d8419e5bade06000998602af6ad/apps/server/src/mcp/toolkits/orchestrator/tools.ts), [migration notice](https://github.com/pingdotgg/t3code/issues/14871), [Nimbalyst hierarchy](https://github.com/nimbalyst/nimbalyst/blob/e506dfca634659dac0eb522aa64e32f30501a9b6/docs/SESSION_HIERARCHY.md), [alpha release](https://github.com/nimbalyst/nimbalyst/releases/tag/v0.80.5).
- **An external manager is a distinct product shape.** Documented: Conductor supplies a cloud manager prompt/MCP; Sculptor supplies cross-workspace delegate-and-wait commands. Inferred: Sotto can expose a small local contract without inventing another worker harness. [Conductor API](https://www.conductor.build/docs/api), [Sculptor CLI](https://github.com/imbue-ai/sculptor/blob/f847102ada1d6896bf6a3a5eccde996760526d9e/sculptor/sculptor-plugin/skills/sculpt-cli/SKILL.md).
- **The recurring attention failure is one badge standing for several states.** Observed: Source and issue evidence distinguish waiting on a human, background work, silent terminals and unfinished housekeeping. Stop or silence is not completion. [Sculptor status](https://github.com/imbue-ai/sculptor/blob/f847102ada1d6896bf6a3a5eccde996760526d9e/sculptor/sculptor/web/derived.py), [Superset background report](https://github.com/superset-sh/superset/issues/8120), [T3 checkpoint report](https://github.com/pingdotgg/t3code/issues/15124).
- **The best message idea is to preserve the user's pending turn.** Inferred: cmux's hook mailbox, delivery states and hold-behind-question behavior are more useful than typing into arbitrary terminals. Its proposed fan-out scheduler is not a shipping claim. [cmux messages](https://github.com/manaflow-ai/cmux/blob/v0.65.0/docs/agent-messages.md), [proposed RFC](https://github.com/manaflow-ai/cmux/blob/v0.65.0/docs/agent-fan-out-rfc.md).
- **Parallel checkout isolation does not settle integration.** Observed: Vendor docs and issues show shared ports/databases, dirty target checkouts and same-workspace edits. Most reviewed integrations still rely on Git plus a human or agent resolving conflicts. [Superset explanation](https://github.com/superset-sh/superset/blob/edcec5b936643560165b90af730d70d742616156/apps/marketing/content/blog/agent-orchestration-not-another-agent.mdx), [Vibe Kanban merge report](https://github.com/BloopAI/vibe-kanban/issues/3324), [Sculptor agents](https://github.com/imbue-ai/sculptor/blob/f847102ada1d6896bf6a3a5eccde996760526d9e/docs/help/agents.md).
- **None of the reviewed references establishes Sotto's permission invariant end to end.** Observed: Implementations include manager answers, provider automatic review, bypass flags or unguarded terminal sends. Inferred: copy coordination ideas while keeping human permissions outside manager tools. [Nimbalyst permission-answer tool](https://github.com/nimbalyst/nimbalyst/blob/e506dfca634659dac0eb522aa64e32f30501a9b6/packages/electron/src/main/mcp/metaAgentServer.ts), [Agent Deck policy](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/internal/session/conductor_templates.go), [Claude Squad daemon](https://github.com/smtg-ai/claude-squad/blob/ce1ffb4392b01f38e2c4599c7c84d2a93973b138/daemon/daemon.go).
- **There is no verified universal five/ten-agent breakpoint.** Observed: Nimbalyst deliberately caps each manager at four in-flight children. Reports range from problems with two sessions to hundreds of retained workspaces; they identify lifecycle, polling, spend and attention risks, not benchmark capacity. Terragon's service died; Vibe Kanban's original business shut down while local source remains. [Capacity source](https://github.com/nimbalyst/nimbalyst/blob/e506dfca634659dac0eb522aa64e32f30501a9b6/packages/electron/src/main/services/metaAgentSessionQueries.ts), [two-session RAM report](https://github.com/manaflow-ai/cmux/issues/17315), [large-fleet report](https://github.com/superset-sh/superset/issues/8108), [Terragon shutdown](https://www.terragonlabs.com/), [Vibe Kanban shutdown](https://vibekanban.com/blog/shutdown).

## Agent Deck

- **What it is.** Documented: Ashesh Goplani's MIT Go/tmux session manager for macOS, Linux and Windows through WSL. Snapshot v1.16.26, October 4, 2026; source 34cf3690. The hardware AgentDeck controller is a different project. [Repository](https://github.com/asheshgoplani/agent-deck), [release](https://github.com/asheshgoplani/agent-deck/releases/tag/v1.16.26), [other AgentDeck](https://github.com/leonj1/agentdeck).
- **Command-center shape.** Documented: TUI/browser fleet view and a persistent Conductor conversation supervising sessions. Observed: a Maestro can supervise conductors; Command Center sends to it or a selected conductor. This remains profile-scoped. [Conductor](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/docs/conductor/README.md), [Command Center](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/docs/COMMAND-CENTER.md), [Maestro](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/internal/session/maestro.go), [target routing](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/internal/web/handlers_command_center.go).
- **Dispatch.** Observed: launch creates, starts and prompts workers; parent IDs establish the roster. Worktrees are optional. [Instructions](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/conductor/conductor-claude.md), [README](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/README.md).
- **What the hub sees.** Documented: app IDs, paths, provider, group, state and terminal output; cost tracking and conversation search. Output is ANSI-stripped/bounded; complete output remains on disk. [Instructions](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/conductor/conductor-claude.md), [README](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/README.md), [Conductor](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/docs/conductor/README.md).
- **Talking to workers.** Observed: session send gates on readiness and can wait for replies. Durable inboxes deliver completions at turn boundaries/heartbeats; an optional ledger records sends, delivery outcomes and message text. [Instructions](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/conductor/conductor-claude.md), [communications](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/docs/comms.md).
- **Attention and approvals.** Documented: fresh hooks outrank terminal cues; fallback uses spinners, glyphs and menus. NEED routes escalation. Observed: policy permits confident automatic answers and Codex approval commands; learnings can become policy. Claude Conductor settings separately require confirmation for sends/launches/lifecycle changes. This does not enforce Sotto's user-only permission boundary. [Status audit](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/docs/status-detection.md), [instructions](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/conductor/conductor-claude.md), [settings](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/internal/session/conductor_claude_settings.go), [policy](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/internal/session/conductor_templates.go).
- **Isolation and merge.** Observed: default sibling &lt;repo&gt;-&lt;sanitized-branch&gt; paths, with .worktrees/custom options. Worktree finish merges, removes checkout/session and optionally branch; merge failures abort. Orphan cleanup defaults to dry run. A semantic conflict solver was not verified. [Git code](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/internal/git/git.go), [finish/cleanup](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/cmd/agent-deck/worktree_cmd.go).
- **Memory and continuity.** Documented: instructions, policy, learnings, state JSON and task log survive compaction. User report: restarting can restore the Conductor process without a recovery turn, leaving work dormant. [Conductor](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/docs/conductor/README.md), [restart issue](https://github.com/asheshgoplani/agent-deck/issues/2518).
- **Voice and mobile.** Documented: optional Telegram/Slack/Discord control and authenticated browser UI. Voice in this project was not verified; the separate hardware project advertises it. [Conductor](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/docs/conductor/README.md), [README](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/README.md), [other AgentDeck](https://github.com/leonj1/agentdeck).
- **Providers.** Documented: many CLIs, including Claude, Codex, Gemini and OpenCode; Conductor choices include Claude, Codex, Hermes and Pi. [README](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/README.md), [Conductor](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/docs/conductor/README.md).
- **Does well.** Inferred: the closest literal persistent-conversation reference, with a roster, durable reports and quiet escalation. [Conductor](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/docs/conductor/README.md).
- **Falls short.** Observed: open user reports: an OpenCode logo looks busy and blocks initial sends; unprefixed replies can reach the alphabetically first Conductor; remote inbox draining can leak reports across profiles. These are specific reports, not failure rates. [Status issue](https://github.com/asheshgoplani/agent-deck/issues/2519), [routing issue](https://github.com/asheshgoplani/agent-deck/issues/2547), [profile issue](https://github.com/asheshgoplani/agent-deck/issues/2539).
- **For Sotto.** Inferred: take durable per-thread delivery, explicit stale state and quiet escalation. [Status audit](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/docs/status-detection.md), [communications](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/docs/comms.md).
  Avoid learning authority from memory, supervisor approvals and message-text logs. [Policy](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/internal/session/conductor_templates.go), [communications](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/docs/comms.md).

## Superset

- **What it is.** Documented: Superset Inc.'s source-available workbench under Elastic License 2.0. macOS supported, Linux experimental, Windows planned. Local individual tier free; Pro $20/person/month, or $15/person/month billed yearly. Snapshot desktop v1.37.0, October 8, 2026; main edcec5b9. [Licence](https://github.com/superset-sh/superset/blob/edcec5b936643560165b90af730d70d742616156/LICENSE.md), [FAQ](https://docs.superset.sh/faq), [pricing](https://superset.sh/pricing), [release](https://github.com/superset-sh/superset/releases/tag/desktop-v1.37.0).
- **Command-center shape.** Documented: dashboard/board/terminals plus a shipped orchestration skill that turns the current Claude/Codex conversation into the coordinator of other agents. [Orchestration](https://github.com/superset-sh/superset/blob/edcec5b936643560165b90af730d70d742616156/apps/docs/content/docs/orchestration.mdx).
- **Dispatch.** Observed: coordinator creates bounded tasks, shallow dependencies and a task/workspace/host/terminal mapping; ready independent workers run first, results feed dependents. Mixed providers and remote hosts are supported. [Skill](https://github.com/superset-sh/superset/blob/edcec5b936643560165b90af730d70d742616156/plugins/superset/skills/orchestrate/SKILL.md).
- **What the hub sees.** Documented: terminal text, diffs, branch divergence, PR checks/reviews and board state. Observed: a listed terminal is explicitly not proof of completion; the coordinator must read and verify. [Workspaces](https://github.com/superset-sh/superset/blob/edcec5b936643560165b90af730d70d742616156/apps/docs/content/docs/workspaces.mdx), [skill](https://github.com/superset-sh/superset/blob/edcec5b936643560165b90af730d70d742616156/plugins/superset/skills/orchestrate/SKILL.md).
- **Talking to workers.** Observed: terminal read/send and MCP carry follow-ups. DONE/BLOCKED envelopes are prompt conventions, not durable events. The coordinator relays dependencies; a peer mailbox was not verified. [Skill](https://github.com/superset-sh/superset/blob/edcec5b936643560165b90af730d70d742616156/plugins/superset/skills/orchestrate/SKILL.md), [MCP](https://github.com/superset-sh/superset/blob/edcec5b936643560165b90af730d70d742616156/apps/docs/content/docs/mcp-server.mdx).
- **Attention and approvals.** Documented: hooks/wrappers drive working/finished/waiting; some providers signal only completion. Inline chat presents questions/permissions. Observed: terminal transport accepts arbitrary text; an enforced prohibition on coordinator answers to permissions could not be verified. [Status](https://github.com/superset-sh/superset/blob/edcec5b936643560165b90af730d70d742616156/apps/docs/content/docs/agent-status.mdx), [skill](https://github.com/superset-sh/superset/blob/edcec5b936643560165b90af730d70d742616156/plugins/superset/skills/orchestrate/SKILL.md).
- **Isolation and merge.** Observed: default ~/.superset/worktrees/&lt;project&gt;/&lt;branch&gt;. The skill does not merge workers automatically. Deletion archives, checks dirty state, tears down, removes PTYs/worktree and optionally branch; failures restore visibility. Its dirty-race retry forces deletion after confirmation. [Path code](https://github.com/superset-sh/superset/blob/edcec5b936643560165b90af730d70d742616156/apps/desktop/src/lib/trpc/routers/workspaces/utils/resolve-worktree-path.ts), [skill](https://github.com/superset-sh/superset/blob/edcec5b936643560165b90af730d70d742616156/plugins/superset/skills/orchestrate/SKILL.md), [delete lifecycle](https://github.com/superset-sh/superset/blob/edcec5b936643560165b90af730d70d742616156/apps/desktop/docs/WORKSPACE_DELETE_LIFECYCLE.md).
- **Memory and continuity.** Documented: daemon processes survive UI restarts; known sessions can resume after reboot. Observed: task/dependency mappings remain coordinator context, with instructions to reconstruct terminal IDs after loss. A durable orchestration graph was not verified. [Daemon behavior](https://github.com/superset-sh/superset/blob/edcec5b936643560165b90af730d70d742616156/apps/marketing/content/blog/agent-orchestration-not-another-agent.mdx), [skill](https://github.com/superset-sh/superset/blob/edcec5b936643560165b90af730d70d742616156/plugins/superset/skills/orchestrate/SKILL.md).
- **Voice and mobile.** Documented: iPhone app launched September 21, requiring iOS 26 and Pro; prompt agents and inspect terminals/diffs. Android/push were forthcoming in the FAQ. Voice coordination was not verified. [Mobile launch](https://superset.sh/blog/superset-mobile), [FAQ](https://docs.superset.sh/faq).
- **Providers.** Documented: installed CLIs plus built-in chat; Claude/Codex coordinate mixed workers. [Overview](https://docs.superset.sh/overview), [orchestration](https://github.com/superset-sh/superset/blob/edcec5b936643560165b90af730d70d742616156/apps/docs/content/docs/orchestration.mdx).
- **Does well.** Inferred: explicit worker contracts and evidence-based completion distinguish agent claims from verified results. [Skill](https://github.com/superset-sh/superset/blob/edcec5b936643560165b90af730d70d742616156/plugins/superset/skills/orchestrate/SKILL.md).
- **Falls short.** Observed: user reports: parent Stop marks review while background work continues; hook parsing delays prompts; 209 workspaces/20 TUIs stall typing. Reports concern versions 1.33, 1.31 and 1.35, not verified defects in 1.37. Vendor says worktrees share ports, databases and machine resources. [Background issue](https://github.com/superset-sh/superset/issues/8120), [hook issue](https://github.com/superset-sh/superset/issues/8245), [scale issue](https://github.com/superset-sh/superset/issues/8108), [vendor explanation](https://github.com/superset-sh/superset/blob/edcec5b936643560165b90af730d70d742616156/apps/marketing/content/blog/agent-orchestration-not-another-agent.mdx).
- **For Sotto.** Inferred: take bounded briefs and independent evidence of completion. [Skill](https://github.com/superset-sh/superset/blob/edcec5b936643560165b90af730d70d742616156/plugins/superset/skills/orchestrate/SKILL.md).
  Avoid text-marker-only results and transient coordinator context as the responsibility ledger; keep permissions in Sotto policy records. [Skill](https://github.com/superset-sh/superset/blob/edcec5b936643560165b90af730d70d742616156/plugins/superset/skills/orchestrate/SKILL.md).

## T3 Code

- **What it is.** Documented: pingdotgg's free MIT control surface for locally installed agents, with Windows/macOS/Linux desktop, web, iOS and Android clients. Snapshot main 393ff4c9, October 8, 2026; build v0.0.46-preview.20261008.2848 is a prerelease. V2 below is implemented preview/nightly behavior; stable mobile remained V1 at the migration notice. [README](https://github.com/pingdotgg/t3code/blob/393ff4c968073d8419e5bade06000998602af6ad/README.md), [preview release](https://github.com/pingdotgg/t3code/releases/tag/v0.0.46-preview.20261008.2848), [migration notice](https://github.com/pingdotgg/t3code/issues/14871).
- **Command-center shape.** Observed: registered MCP tools list/read/send/launch/wait/interrupt threads. Inferred: an ordinary tool-enabled conversation can coordinate a fleet; a distinct global-manager page was not verified. [Orchestrator tools](https://github.com/pingdotgg/t3code/blob/393ff4c968073d8419e5bade06000998602af6ad/apps/server/src/mcp/toolkits/orchestrator/tools.ts), [launch tools](https://github.com/pingdotgg/t3code/blob/393ff4c968073d8419e5bade06000998602af6ad/apps/server/src/mcp/toolkits/project/tools.ts), [launch handler](https://github.com/pingdotgg/t3code/blob/393ff4c968073d8419e5bade06000998602af6ad/apps/server/src/mcp/toolkits/project/handlers.ts).
- **Dispatch.** Documented: delegate_task creates app-owned child threads with self-contained briefs, provider/model/role selection and wait/async modes; parent history is not copied. create_threads creates 1–20 threads in the caller's checkout; launch explicitly chooses root/new worktree/existing checkout. [MCP contract](https://github.com/pingdotgg/t3code/blob/393ff4c968073d8419e5bade06000998602af6ad/docs/orchestration-v2/orchestrator-mcp-server.md).
- **What the hub sees.** Observed: durable state, run history, plans and paginated messages/activity, including tools, checkpoints, handoffs and runtime requests. Documented: usage combines tokens/cache savings and estimated API-equivalent costs, distinct from subscription bills. [Handlers](https://github.com/pingdotgg/t3code/blob/393ff4c968073d8419e5bade06000998602af6ad/apps/server/src/mcp/toolkits/orchestrator/handlers.ts), [usage](https://github.com/pingdotgg/t3code/blob/393ff4c968073d8419e5bade06000998602af6ad/docs/user/usage.md).
- **Talking to workers.** Documented: app-owned thread IDs target auto/queue/steer/interrupt-and-restart sends. Retry keys make sends idempotent; launch has no retry key, so check the roster after a lost reply; async completion notifies the parent. Separate top-level threads require the user's request. [Tools](https://github.com/pingdotgg/t3code/blob/393ff4c968073d8419e5bade06000998602af6ad/apps/server/src/mcp/toolkits/orchestrator/tools.ts), [launch contract](https://github.com/pingdotgg/t3code/blob/393ff4c968073d8419e5bade06000998602af6ad/apps/server/src/mcp/toolkits/project/tools.ts).
- **Attention and approvals.** Observed: typed runtime-request events feed durable projections. Documented: sidebar returns finished/failed/answer/approval threads to attention; initial permission default is Full access, with supervised/auto-edit/Auto review alternatives. MCP mutations cannot exceed the caller's mode. No approval-answer tool was found on this orchestration surface; that does not prohibit automatic decisions elsewhere. [Event ingestor](https://github.com/pingdotgg/t3code/blob/393ff4c968073d8419e5bade06000998602af6ad/apps/server/src/orchestration-v2/ProviderEventIngestor.ts), [sidebar](https://github.com/pingdotgg/t3code/blob/393ff4c968073d8419e5bade06000998602af6ad/docs/user/thread-sidebar.md), [permissions](https://github.com/pingdotgg/t3code/blob/393ff4c968073d8419e5bade06000998602af6ad/docs/user/permission-modes.md), [tool access](https://github.com/pingdotgg/t3code/blob/393ff4c968073d8419e5bade06000998602af6ad/apps/server/src/mcp/McpToolAccess.ts).
- **Isolation and merge.** Observed: default &lt;T3 home&gt;/worktrees/&lt;repo&gt;/&lt;sanitized-branch&gt;; normal Git dirty-file checks unless forced, gone worktrees pruned. Shared references prevent orphan cleanup. Documented: stacks can merge/rebase under GitHub rules/queues; conflicts may require humans. No automatic semantic worker merge guarantee. [Git driver](https://github.com/pingdotgg/t3code/blob/393ff4c968073d8419e5bade06000998602af6ad/apps/server/src/vcs/GitVcsDriverCore.ts), [cleanup](https://github.com/pingdotgg/t3code/blob/393ff4c968073d8419e5bade06000998602af6ad/apps/web/src/worktreeCleanup.ts), [source control](https://github.com/pingdotgg/t3code/blob/393ff4c968073d8419e5bade06000998602af6ad/docs/user/source-control.md).
- **Memory and continuity.** Documented: V2 commands/results/projections are durable. Migration copies state.sqlite to statev2.sqlite, preserving conversations/projects/worktrees but dropping live sessions and old checkpoint/tool/approval history; continuation starts a fresh provider with bounded history. [MCP contract](https://github.com/pingdotgg/t3code/blob/393ff4c968073d8419e5bade06000998602af6ad/docs/orchestration-v2/orchestrator-mcp-server.md), [migration](https://github.com/pingdotgg/t3code/issues/14871).
- **Voice and mobile.** Documented: supported iOS 26 devices transcribe voice on-device into editable drafts, with temporary audio then deletion. Background alerts require T3 Connect, beyond direct/Tailscale access. Spoken supervision was not verified. ## Gaps nobody fills well

The reviewed evidence does not establish that no other product fills these gaps. These are gaps in the references checked.

- **A private, global conversation with enforced human-only permissions.** Inferred: managers exist, but the nearest references use narrower scope, cloud control or delegated/bypassed permissions. Sotto's opportunity is the complete boundary, not merely another roster. [Agent Deck scope](https://github.com/asheshgoplani/agent-deck/blob/34cf3690c39614f33aa683e8f8a280322320de59/docs/COMMAND-CENTER.md), [Nimbalyst answers](https://github.com/nimbalyst/nimbalyst/blob/e506dfca634659dac0eb522aa64e32f30501a9b6/packages/electron/src/main/mcp/metaAgentServer.ts), [Conductor MCP](https://www.conductor.build/docs/api/mcp).
- **Reliable attention through background work, disconnects and restarts.** Observed: issue reports show false work/wait states, delayed alerts and dormant recovered supervisors. None supplies a benchmark proving fleet-wide reliability. [T3 subscription report](https://github.com/pingdotgg/t3code/issues/15289), [HumanLayer alerts](https://github.com/humanlayer/humanlayer/issues/1125), [Agent Deck recovery](https://github.com/asheshgoplani/agent-deck/issues/2518).
- **Dependency-aware integration with evidence from the combined result.** Inferred: planning, worker isolation and Git helpers exist, but no reviewed source proves general semantic conflict resolution plus final user-journey verification. [Superset integration contract](https://github.com/superset-sh/superset/blob/edcec5b936643560165b90af730d70d742616156/plugins/superset/skills/orchestrate/SKILL.md), [T3 stacks](https://github.com/pingdotgg/t3code/blob/393ff4c968073d8419e5bade06000998602af6ad/docs/user/source-control.md).
- **Voice supervision across a fleet with preserved pending answers.** Documented voice input/mobile replies exist; cmux voice is early access and Nimbalyst has question-preemption reports. A reliably shipped spoken global supervisor was not verified. [T3 voice](https://github.com/pingdotgg/t3code/blob/393ff4c968073d8419e5bade06000998602af6ad/docs/user/composer.md), [cmux early access](https://github.com/manaflow-ai/cmux/blob/v0.65.0/README.md), [Nimbalyst question report](https://github.com/nimbalyst/nimbalyst/issues/1557).

### Could not verify

- **Runtime and scale, all products:** current regression reproduction, comparative failure rates, practical five/ten-worker capacity, semantic merge correctness, or real-world mobile/voice reliability. This was research only; reports and vendor fixes are evidence, not our tests.
- **Agent Deck / Superset:** robust recovery/delivery across every profile/host; voice in the Go Agent Deck project; supervisor-proof permission boundaries; durable Superset dependency state. Superset Android and push remained forthcoming [Recovery report](https://github.com/asheshgoplani/agent-deck/issues/2518), [Superset skill](https://github.com/superset-sh/superset/blob/edcec5b936643560165b90af730d70d742616156/plugins/superset/skills/orchestrate/SKILL.md), [FAQ](https://docs.superset.sh/faq).
- **T3:** stable V2 availability across clients, a separate global-manager page and spoken supervision. V2 launch is implemented but not retry-idempotent; stable mobile compatibility differs from preview [Migration notice](https://github.com/pingdotgg/t3code/issues/14871), [launch tools](https://github.com/pingdotgg/t3code/blob/393ff4c968073d8419e5bade06000998602af6ad/apps/server/src/mcp/toolkits/project/tools.ts), [composer guide](https://github.com/pingdotgg/t3code/blob/393ff4c968073d8419e5bade06000998602af6ad/docs/user/composer.md).
