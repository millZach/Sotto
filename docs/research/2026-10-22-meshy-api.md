# Meshy's API, prices and data terms

Read October 22, 2026 from Meshy's own docs, terms and repositories, for [ADR-0141](../adr/0141-a-thread-makes-3d-models-with-meshy-and-asks-before-each.md). Most pages were read through a summarizing fetch, so check exact wording against the page before quoting it.

## Hosts

- `api.meshy.ai`: every API call, under `/openapi/v1/` and `/openapi/v2/` ([OpenAPI spec](https://docs.meshy.ai/openapi.json), [quickstart](https://docs.meshy.ai/en/api/quick-start)).
- `assets.meshy.ai`: model files, textures and thumbnails, under signed links with `Expires` and `Signature` ([asset retention](https://docs.meshy.ai/en/api/asset-retention)). Not checked for rigging and animation output.
- Account pages only: `www.meshy.ai` (keys), `docs.meshy.ai`, `help.meshy.ai`, `status.meshy.ai`.
- Webhooks go from Meshy to a public `https://` address of the customer's ([webhooks](https://docs.meshy.ai/en/api/webhooks)), which a desktop app does not have, so Sotto polls.

## Tasks

Every call sends `Authorization: Bearer <key>`. Creating a task answers `{"result": "<task id>"}`.

- Text to 3D: `POST /openapi/v2/text-to-3d`, `mode` `preview` (prompt up to 800 characters) then `refine` with `preview_task_id` ([text-to-3d](https://docs.meshy.ai/en/api/text-to-3d)).
- Image to 3D: `POST /openapi/v1/image-to-3d`, `image_url` as a public link or a data address, JPG, PNG or WebP up to 20 MB; `should_texture`, `enable_pbr`, `texture_resolution` ([image-to-3d](https://docs.meshy.ai/en/api/image-to-3d)). Multi-image: `POST /openapi/v1/multi-image-to-3d`, one to four images ([multi-image](https://docs.meshy.ai/en/api/multi-image-to-3d)).
- Also offered and not used in the first version: remesh, retexture, rigging, animation, text to motion.
- Progress: `GET` the task, waiting for `Retry-After` or five seconds ([quickstart](https://docs.meshy.ai/en/api/quick-start)); or `GET .../:id/stream` as server-sent events. Statuses `PENDING`, `IN_PROGRESS`, `SUCCEEDED`, `FAILED`, `CANCELED`; a failed task is refunded ([task lifecycle](https://docs.meshy.ai/en/api/task-lifecycle)). Usually a few minutes.
- Retention: at most three days for non-Enterprise API output, after which a link answers 400 ([asset retention](https://docs.meshy.ai/en/api/asset-retention), [terms §2.5](https://www.meshy.ai/cs/terms-of-use)). One help article says two months for rigging; the two disagree.

## Formats

`model_urls` may hold `glb`, `fbx`, `obj` with `mtl`, `usdz`, `stl`, `3mf` (only when asked for) and `pre_remeshed_glb`; texture maps; `thumbnail_url` and optional side views ([image-to-3d](https://docs.meshy.ai/api/image-to-3d.md)). `video_url` is deprecated.

## Keys, prices and limits

- Keys are made at [meshy.ai/developers/keys](https://www.meshy.ai/developers/keys) on a paid plan, each with an optional monthly credit cap and IP allowlist ([authentication](https://docs.meshy.ai/en/api/authentication)). The shared test key was retired September 16, 2026 ([changelog](https://docs.meshy.ai/api/changelog.md)).
- Plans: Free has no API access (402); Pro $20 for 1,000 credits; Premium $40 for 3,000; Ultra $100 for 8,000 ([pricing](https://meshy.ai/pricing)). No per-credit API rate is published; Pro works out to about two cents.
- Credits ([API pricing](https://docs.meshy.ai/en/api/pricing)): text-to-3D preview 20, refine 10 (15 at 8K); image-to-3D 20, textured 30 (35 at 8K); remesh 5; retexture 10. Deleting a pending task refunds; deleting a running one answers 409 and does not ([changelog](https://docs.meshy.ai/api/changelog.md)).
- Rate limits: Pro 20 requests a second and 10 tasks at once ([rate limits](https://docs.meshy.ai/en/api/rate-limits)).

## Data

- Terms §2.9: Meshy may use non-Enterprise customers' inputs and outputs to train, validate, test or improve its services ([terms](https://www.meshy.ai/cs/terms-of-use)). §3.2 lets paid customers keep their content private, without squaring it with §2.9.
- The help centre says non-Enterprise data may be used, anonymized, for training, Enterprise data is not, and data is stored with AWS in the United States ([data and training FAQ](https://help.meshy.ai/en/articles/15724182-is-meshy-safe-and-private-data-and-training-faq)).
- The privacy policy allows data to be stored anywhere in the world ([privacy policy](https://meshy.ai/privacy-policy)).
- No document offers a non-Enterprise way to opt out of training.

## Meshy's own integrations

- MCP server `@meshy-ai/meshy-mcp-server`, MIT, 28 tools, key from `MESHY_API_KEY`, files to `meshy_output/` ([repository](https://github.com/meshy-dev/meshy-mcp-server)).
- Skills and a Claude Code plugin, [meshy-3d-agent](https://github.com/meshy-dev/meshy-3d-agent), over `meshy-cli`, which keeps its sign-in in `~/.config/meshy/credentials.json`. Meshy's docs list the same skills for Hermes Agent ([Hermes page](https://docs.meshy.ai/en/webapp/plugins/hermes-agent/introduction)).
