## Top 3

1. **#1691: A paired client can merge a pull request without the surface's confirmation.** Security. Any paired token can merge, close or turn on auto-merge for a linked pull request, and nothing between the socket and `gh pr merge` asks. That breaks "the user answers every permission". The fix is contained (the remote allow-list, one host-side check and a socket test) but changes the remote contract, so it amends ADR-0027.
2. **#1385: folderRemoval test sometimes removes a held folder on the Windows CI runner.** Flake on a required check. It failed Tests (Windows, 3/6), and so Gates (Windows), on at least nine runs since October 23, once on `main`, most recently on October 27 and 28. The likely cause is named in the issue: `holdFolder` resolves when the child is spawned, not when it is holding the folder. Small, test-only.
3. **#1511: A Claude send after a restart reads uncertain although Claude Code echoed it.** User-facing bug. On two wake-ups after restarts, a Claude thread's send waited out the 15-second acknowledgement and read uncertain, although Claude Code took it. An uncertain send can hold later ones, and Zach runs Claude threads all day. How often it happens is not measured. The cause is unknown; the issue names four places in `claude.ts` that could drop the echo. Medium effort.
