# Connected and disconnected providers in Settings

On November 22, 2026, the Windows Electron app showed one connected Codex fixture above nine disconnected clients. The disconnected rows started folded. Enter on **Disconnected providers** showed Devin’s row. Escape on the row closed the group and returned keyboard focus to the disclosure. The journey checked dark and light at 1600×1000, 1280×800 and 820×560 and measured the Providers section for horizontal overflow. [Windows menu journey and captures](https://github.com/millZach/Sotto/actions/runs/45036230767/job/137250482315).

The renderer checks covered a client reporting a connection change while its details were open, a settings link to a disconnected Claude Code, the sign-in and install actions, and a remote host selected for new work. The five focused test files passed all 84 tests on Windows. [Windows test results](https://github.com/millZach/Sotto/actions/runs/45036230767/job/137250482315).

The design captures use the normal first-run fixture. The Settings capture shows the starting state before any provider has reported a connection. The setup walk highlights the group heading and the disclosure together.
