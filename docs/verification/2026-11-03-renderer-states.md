## Listed decision

Council's estimate read catches a bridge rejection without setting an estimate. The Ask form then uses its generic provider/thread-count explanation, without the conversation size. The code also represents an intentionally unavailable estimate with a message from main. Whether a failed estimate should block asking, offer retry or remain optional is not established by a sibling. No new wording or policy was invented here. See the estimate effect and `reads` fallback in [CouncilView](../../src/renderer/src/features/council/CouncilView.tsx).
