# Delegated threads in Tools › Agents — 2026-10-17

An orchestrating thread that starts many delegated threads (ADR-0081) crowded the sidebar, where each sat under the thread that started it. Zach picked variant B of the delegated threads roster prototype on October 17, 2026: delegated threads leave the sidebar and are listed in the delegating thread's Tools › Agents, mixed with its provider's own agents, newest start first, and each opens as a thread. ADR-0081's Consequences record the decision. This note records what the running app now shows and how that was checked. All of it is behind the `thread-delegation` Owl feature; stable is unchanged.

## What Sotto does now

- **The sidebar.** A delegated thread has no row at either level, and a search does not find it. The exception is a delegated thread whose delegating thread is gone from the state, or a loop of links: it keeps its own row, so it is never out of reach.
- **Needs you rolls up.** When a delegated thread below a thread, at either level, waits for a permission or an answer, that thread's row says Needs your approval or Needs your answer with the attention ring, and its accessible description names the delegated thread ("Waiting in Review the reconnect diff"). A permission below outranks a question below, and the thread's own waiting wins. The panes keep the thread's own row.
- **The roster.** Tools › Agents lists the thread's delegated threads, and theirs under them, mixed with its agents by start time, newest first. A delegated thread's row has its provider's mark, a Thread tag, its brief, then its provider, kind of work, model, effort and start time as far as the delegation record and the snapshot know them, its outcome in the glossary's words and how long it has taken. Opening the row shows the brief and the latest outcome; the reply never shows. The line of chrome counts both: "1 delegated thread", "4 delegated threads · 2 agents", with "1 needs you · 2 working" beside it.
- **Opening one.** Open as thread shows it in the pane. The sidebar keeps the delegating thread marked as current, and Tools stays on that thread's roster, pinned, where the row reads In the pane. A thread waiting on you reads Open to answer, with the attention edge and tint, and its accessible name says what a press does: "Open Review the reconnect diff to answer its request". The transcript card's link opens a delegated thread the same way.
- **Dots.** The Tools toggle and the Agents tab take an attention dot while a delegated thread below the thread waits on you, and the toggle's working dot counts delegated threads that are working.
- **Agents and the pin.** With delegation on, Agents follows the Tools pin like the other surfaces, and Agents offers Pin. Without it, Agents follows the focused thread, as before.
