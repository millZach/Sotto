## What to build

New independent coding tasks get their own working copy and branch, with an explicit shared-working-copy option.

## Acceptance criteria

- [ ] Create/reuse a Git worktree during thread creation and bind all provider commands to the actual working directory.
- [ ] Offer a deliberate shared-working-copy path for collaborating threads; existing threads remain in their current folders and non-Git folders remain usable.
- [ ] Worktree setup failure leaves a recoverable thread draft and never routes a task into the wrong directory; preserve project-level memory scope across worktrees.
- [ ] Verify concurrent native threads do not overwrite each other's working files. Include worktree status/open/reveal behavior and preserve user changes during cleanup.
