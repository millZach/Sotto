## What to build

Drag a thread from the sidebar beside the current thread and use both independently.

## Acceptance criteria

- [ ] Dragging a second thread splits available space evenly; dividers resize and either thread can receive input without draft or selection leakage.
- [ ] Both views retain their own message position, provider controls and activity; cross-project panes are supported.
- [ ] Closing a pane closes only its view; the agent keeps working and remains reachable in the sidebar.
- [ ] Provide a keyboard-accessible way to open/focus/close a split and verify minimum-width behavior. Extract a reusable thread-view boundary only as needed for this slice.
