## What to build

Open a Files surface beside a thread and inspect files in that thread's actual working directory.

## Acceptance criteria

- [ ] Provide a reusable side-panel surface selector and file tree with readable text/Markdown/image previews and copyable paths.
- [ ] Panel follows the focused thread and can be pinned; paths and workspace identity remain visible when focus changes.
- [ ] Read the thread's bound working directory, including a worktree when present; missing files and unavailable folders produce recoverable states.
- [ ] Retain panel state across focus changes and integrate with split panes when available. Verify actual Electron file browsing without exposing unrestricted renderer filesystem access.
