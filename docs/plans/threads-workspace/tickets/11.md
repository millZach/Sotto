## What to build

Arrange more threads with the agreed snapping rules and restore the arrangement after restart.

## Acceptance criteria

- [ ] A third thread spans the row below the first two; a fourth creates a 2-by-2 grid. A single-row arrangement is available with adjustable dividers.
- [ ] Persist arrangement, selected threads and sizing; reopen existing threads without starting new native work.
- [ ] Offer focus/zoom for smaller windows and return to the retained layout. One-through-four arrangements are defaults, not an implicit hard cap.
- [ ] Handle closing, moving and adding panes without losing drafts or live state; verify cross-project layout and recovery at desktop/minimum sizes.
