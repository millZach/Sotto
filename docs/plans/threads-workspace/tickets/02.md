## What to build

Navigate project folders containing multiple threads, with recognizable provider icons and reversible Settled groups.

## Acceptance criteria

- [ ] Create/open projects and create multiple threads under each; retain existing thread IDs, provider bindings, project memory scopes and disconnected-provider history.
- [ ] Settle a thread and restore it under its owning project. Settle an entire project and restore its thread group without changing individual prior settled states.
- [ ] Retain search and working/attention indicators. Settling or hiding a view never deletes history, working files, branches or running native work.
- [ ] An empty unstarted thread may choose any ready provider; a started native conversation stays with its original provider. Same-provider controls respect native capabilities. Verify the existing provider/coordinator separation.

## Blocked by

None — can start immediately on the agreed integration baseline.

## Shared constraints

Build on the existing native-provider foundation and the approved Threads workspace specification. Preserve Sotto thread IDs, native provider bindings, scoped memory, explicit management authority and uncertain-delivery reconciliation. Use the inspected T3 reference at commit d1d15c67f4a5fb82fd8d5e01e5e3b288296789c3 as behavioral evidence; retain Sotto styling and the user's explicit differences. No cross-provider continuation, automatic chat-to-project orchestration, skill manager or custom compaction engine. Follow the repository's applicable design, review and platform instructions. A completed slice must include its own focused tests and rendered verification when it changes UI.

Implementation baseline: the existing native-provider work on branch work/thread-providers through commit 52f1f42. Reuse it instead of rebuilding adapters. Confirm that baseline is available before starting; the complete release also requires delivery of existing #24. Existing parent issues and unrelated Dictionary, history-import, hybrid-memory and voice-benchmark work retain their scope.
