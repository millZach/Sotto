# Remove voice control and thread management

October 8, 2026. Planning only, on `command-center`.

October 9 amendment: the accepted removal is ADR-0065 (`docs/adr/0065-remove-voice-control-and-thread-management.md`), renumbered after merging today's main. The inventory below retains the original planning state; runtime evidence is in `docs/verification/2026-10-09-voice-control-removal.md`.

Remove the voice coordinator and the per-thread Manage controls. Keep dictation whole. The typed command center is later work, not part of this pull request. Leave the memory gate, memory storage, memory permissions and Memory page alone.

This plan comes from reading the repository, starting with `AGENTS.md`, `CONTEXT.md`, ADR-0012 and `docs/agent-control.md`, then following the renderer, preload, IPC, coordinator, persistence and host paths. No npm command, build, test or running-app check was performed. The dispositions below are recommendations, not changes already made. Only this file was written. Existing command-center research notes were left untouched.

## Acceptance checks and current state

| Deliverable | Acceptance check | State |
| --- | --- | --- |
| Removal boundary | No wake capture, reply synthesis, voice download, voice setting, Agents room, orb, spoken hint or Manage action can be reached locally or remotely. | Traced; implementation pending. |
| Dictation | The same recorder, segments, transcription request, dictionary, cleanup, kept-recording retry, output, shortcut and pill remain. | Seams identified; runtime verification pending. |
| Upgrade | Old settings and `agents.json` retain threads, drafts, attachments, queues of user follow-ups, outbox and delivery evidence. Old assignments never restart. | Migration specified; tests pending. |
| Hosts and phones | Protocol v1 still reads on old clients; retired commands cannot create authority. Phone answers, creation, photos and needs-you views work. | Compatibility boundary identified; native verification pending. |
| Delivery | One PR, coherent commits, CI gates, affected Electron journeys and inspected captures. | Future work; nothing committed. |
