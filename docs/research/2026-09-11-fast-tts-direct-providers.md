## Recommendation

For low latency plus attractive voice choices, prioritize **Cartesia Sonic 3.6**, **ElevenLabs Flash v2.5**, and **Inworld TTS-2 Flash** as direct-provider challengers. Cartesia is the quality/speed candidate, ElevenLabs offers the clearest broad voice-selection advantage, and Inworld adds a compelling speed/cost test. Retain Grok as the existing hosted control. Deepgram Flux TTS is especially relevant for conversational interruption behavior. These are benchmark priorities, not verified rankings of sound quality.

## Newer expressive alternatives

**Eleven v3 Conversational** is a separate model from ordinary `eleven_v3`: `eleven_v3_conversational`, 70+ languages, audio tags, published ~280 ms latency, and $50/M API list pricing. It deserves a quality-oriented listening arm, but 280 ms already leaves little room under a 300 ms audible application target. Flash remains the vendor's lowest-latency recommendation. Do not infer from older ordinary-v3 advice that Conversational is unavailable or unsuitable. [Model selection](https://elevenlabs.io/docs/eleven-api/choosing-the-right-model), [models](https://elevenlabs.io/docs/overview/models), [pricing](https://elevenlabs.io/pricing/api)

**Hume Octave 2** is an optional expressive/custom-voice reserve. Current docs mark it preview and claim ~100 ms model latency excluding network, with 11 languages, cloning, English-only voice design and acting instructions still listed as coming soon. The launch post's under-200 ms statement is a broader, older claim. Streaming HTTP and bidirectional WebSocket are documented. This does not establish that Hume beats the three preferred challengers in Sotto; no unambiguous Octave-2-specific price was resolved from the pricing page's model toggle in this pass. [Current TTS docs](https://dev.hume.ai/docs/text-to-speech-tts/overview), [launch](https://www.hume.ai/blog/octave-2-launch), [pricing](https://www.hume.ai/pricing)

## How to make the screen fair

All preferred direct providers support streaming; adopting a model while keeping Sotto's whole-WAV accumulation would discard much of that advantage. Cartesia offers HTTP/SSE/WebSocket, raw PCM and context cancellation. ElevenLabs offers HTTP streaming and independent WebSocket contexts; 44.1 kHz PCM has a Pro-tier requirement. Inworld recommends persistent WebSocket, sending text without waiting for context acknowledgment, and asynchronous timestamps to avoid holding back audio. [Cartesia API](https://docs.cartesia.ai/api-reference/tts/websocket), [Eleven stream API](https://elevenlabs.io/docs/api-reference/text-to-speech/stream), [Eleven contexts](https://elevenlabs.io/docs/api-reference/text-to-speech/v-1-text-to-speech-voice-id-multi-stream-input), [Inworld latency guide](https://docs.inworld.ai/tts/best-practices/latency)

Flux's `/v2/speak` WebSocket has persistent turn context and an `Interrupt` message with spoken-text feedback. That can improve conversational handling without changing MAI transcription. It still requires immediate local playback stop; server interruption cannot retract queued speaker audio. [Flux quickstart](https://developers.deepgram.com/docs/flux-tts/quickstart), [interrupt integration](https://developers.deepgram.com/docs/flux-tts/voice-agent)

Screen two or three stock voices per shortlisted provider before the full repeated benchmark. Freeze voice, model, normalization, speed, format, connection state and output buffering. Score code identifiers, numbers, negatives and commands. Keep raw-text and pronunciation-normalized arms separate: Flash's model guide warns number normalization is disabled by default and explicit enablement has Enterprise restrictions. [Flash model details](https://elevenlabs.io/docs/overview/models)

Record request-to-first-byte, first playable PCM, actual audible start, and interruption-to-silence separately. Vendor inference, server p90/p99 TTFB, provider-dashboard latency and application audible p95 are different measurements. This screen provides no measured client performance or blind listening result and authorizes no provider switch.
