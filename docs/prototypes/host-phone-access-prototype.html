Prototype · Sotto · phones on a remote host

Let phones reach forge, from your main computer

Today a phone can reach a computer without a screen only after someone signs in there, runs Tailscale Serve by hand and runs the host's pairing command. Here, the desktop does it over the SSH connection it already has: a switch per host in Settings › Hosts runs Tailscale Serve on that host, shows its pairing code and lists its paired phones, each with Can answer and Remove.

Three layouts. A opens a panel under forge's row. B opens a dialog from the row. C gives forge a page of its own inside Hosts. The bar at the bottom switches layout (← →), forge's state (keys 1–8), theme, motion and window size.
