## What to build

Use the embedded browser for local apps and URLs while ordinary agent links open externally by default.

## Acceptance criteria

- [ ] Default normal web-link clicks to the user's system browser; persist a setting to use the in-app browser instead and expose either destination per link.
- [ ] Embedded browser supports navigation, back/forward, reload, URL display and multiple retained pages needed for daily work.
- [ ] Keep page state across panel focus/pinning; clearly identify the browser destination and handle unavailable local servers.
- [ ] Use the desktop browser security boundary so visited pages do not inherit Sotto's privileged application bridge. Verify an actual local app and an external link.
