## What to build

Open and use an interactive terminal in the active thread's working directory.

## Acceptance criteria

- [ ] Launch a real shell/PTY with input, output, resize, interrupt, scrollback and exit state; support multiple terminal instances needed for a dev server and commands.
- [ ] Keep terminal sessions alive across thread focus and panel hiding; identify the owning directory and respect panel pinning.
- [ ] On app restart show the true terminal lifecycle rather than claiming a dead process resumed; support a clear reopen action.
- [ ] Verify on the target Windows desktop, including a running dev server and shell interruption, and preserve platform-appropriate launch behavior.
