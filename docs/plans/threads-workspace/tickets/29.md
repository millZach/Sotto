## What to build

Generate a useful prompt from a Sotto conversation for the user to copy and use themselves.

## Acceptance criteria

- [ ] Produce objective, relevant decisions/context, constraints/non-goals, deliverables, acceptance checks and unresolved questions, omitting empty sections.
- [ ] Honor the latest corrections and separate accepted decisions from suggestions; do not invent missing requirements or silently resolve contradictions.
- [ ] Show editable/copyable output and preserve the original chat. The action never creates a project, starts a thread or delegates work.
- [ ] Evaluate a representative fixture set of short/long brainstorming, changed decisions and missing details against a documented fidelity/usefulness rubric, including human review before declaring the format proven.
