# Current-session reaper observations (#411)

The full headless and socket contracts sometimes reported no new native start after reaping. Their stopped predicates accepted any historical Claude exit or Grok close, even after that session had resumed. A bounded regression reproduced both errors deterministically: the resumed Claude PID answered a real liveness probe and its snapshot was running, while the fixture still said stopped; a Grok reload likewise remained running after an earlier close while its fixture said stopped. Both desired assertions failed on unchanged fixtures.

Claude now reads the existing current-child ownership marker and probes its PID. Grok's child records residency only after an accepted session mutation, and the fixture reads the last residency event for that native session. A rejected close does not claim that the session stopped. No production adapter, idle threshold, polling cadence or deadline changed.

The corrected observation regressions and full headless/socket host contracts passed: 74 tests across three files. The additional rejected-close assertion passed in the two-test focused repeat. Typecheck, lint and notices passed. Independent native Astra Standards and Spec reviews reported no findings. The frozen full-suite gate at `11d10d14` passed with two workers: 5,831 tests passed and 140 skipped, across 445 passing and 39 skipped files, in 1,011.12 seconds. Every test command set `SOTTO_PERF_DATA` to a verified-absent owned artifact path. Real child processes and temporary fixture directories were used; no paid provider turn or production profile was accessed. This test-only change has no rendered surface.
