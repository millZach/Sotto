C rings the dots a prompt would use once it grows long or names a hard task; nothing changes until you press. Below it as drawn, then four directions. Each Play shows both ways: a long "refactor and debug why" prompt that wants more, then a short "open the pull request" that wants less.

What every direction changes from C: it suggests down as well as up (a lit dot it would drop goes hollow), so High is not the answer to every prompt. Clicking any ringed or hollow dot takes the suggestion; any other dot still sets that level. The suggestion is read from the draft's own words on this computer, and only from the draft: a long prompt, several lines, and words such as refactor, debug, why or investigate push it up; a short task pushes it down.
